# مشروع تطبيق الأندرويد الكامل (APK) - إدارة الحفل وبوابة الاستقبال

يحتوي هذا المجلد على مشروع Android Studio كامل بلغة Kotlin ومجهّز بجميع أذونات الكاميرا الفورية لقراءة الباركود.

## طريقتان سريعتان للحصول على ملف `.apk` وتثبيته:

### الطريقة 1 (سحابية بدون برامج — عبر GitHub Actions خلال دقيقتين):
1. ارفع محتويات مجلد `android-app` إلى مستودع جديد في حسابك على GitHub.
2. افتح تبويب **Actions** ثم اختر **Build Android APK** واضغط **Run workflow**.
3. بعد دقيقتين ستجد ملف **`wedding-organizer-apk.zip`** جاهزاً للتحميل، وبداخله ملف **`app-debug.apk`** يمكنك إرساله للجوال وتثبيته مباشرة.

### الطريقة 2 (عبر برنامج Android Studio على الكمبيوتر):
1. افتح مجلد `android-app` من داخل **Android Studio**.
2. لتغيير رابط التطبيق لاحقاً، عدّل `APP_URL` داخل الملف `app/build.gradle.kts`.
3. من القائمة العلوية اختر:
   `Build > Build Bundle(s) / APK(s) > Build APK(s)`
4. سيتم استخراج ملف `.apk` الجاهز للتثبيت على جميع هواتف الأندرويد مع تفعيل الكاميرا تلقائياً.
